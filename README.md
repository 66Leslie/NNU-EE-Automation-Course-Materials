# 南京师范大学 · 电气与自动化工程学院 · 课程资料

南京师范大学 **电气与自动化工程学院 2023 级 自动化**专业本科课程的**实验报告与源码**合集，
整理出来供本学院学弟学妹参考。**电气工程及其自动化**等专业课程内容相近，亦可参考。

> ⚠️ 本仓库仅供学习参考，**请勿直接抄袭提交**，请遵守学校的学术诚信规定。
> 仓库中不包含教材、教师课件等第三方版权资料；如仍有疏漏，请提 Issue 联系删除。

## 目录结构

每门课统一采用：

```
<课程>/
├── 报告/     # 最终提交版报告（pdf/docx）+ 原始数据/附件
└── 代码/     # 源代码 / 工程文件（MATLAB、Simulink、Verilog、Python 等）
```

> 部分课程为**小组合作**，相关报告在取得全体成员授权后再行补充。
