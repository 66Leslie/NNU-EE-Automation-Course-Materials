# 南京师范大学 · 电气与自动化工程学院 · 课程资料

南京师范大学 **电气与自动化工程学院 2023 级 自动化**专业本科课程的**实验报告、源码、课后作业与学习复习资料**合集，供本学院学弟学妹参考；**电气工程及其自动化**等专业课程内容相近，亦可参考。

> ⚠️ 本仓库仅供学习参考，**请勿直接抄袭提交**，请遵守学校的学术诚信规定。
> 如有不适合公开的资料，请提 Issue 联系处理。

## 目录结构

每门课按实际内容组织，未包含的资料类型不建空目录：

```
<课程>/
├── 报告/          # 最终提交版报告（pdf/docx）+ 原始数据/附件
├── 代码/          # 源代码 / 工程文件（MATLAB、Simulink、Verilog、Python 等）
├── 课后作业/      # 课后作业：照片 + 图片合订 PDF
└── 学习复习资料/  # 学习笔记、复习提纲、课堂资料：照片 + 图片合订 PDF
```

图片资料同时保留原图与压缩 PDF 合订本，完整索引见 [图片资料阅读说明](图片资料阅读说明.md)。

> 部分课程为**小组合作**，相关报告在取得全体成员授权后再行补充。
