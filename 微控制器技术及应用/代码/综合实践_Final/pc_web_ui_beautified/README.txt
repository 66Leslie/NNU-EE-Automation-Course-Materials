电脑端网页使用说明
================

1. 电脑与开发板必须连接同一个热点（SSID/密码在开发板代码中）。
2. 先确认开发板已联网并获取 IP：
   - 开发板待机界面会显示 IP（或串口 AT+CIFSR 查看）。
3. 打开 index.html：
   - 在网页里输入开发板 IP，点击“开始监视”。
   - 网页每 1 秒请求一次：http://<IP>/data
     返回 JSON：state/temperature/humidity/speed。

备注
----
- 若你直接在浏览器输入：http://<IP>/ ，开发板会返回它自带的页面，也能显示状态并自动刷新。
