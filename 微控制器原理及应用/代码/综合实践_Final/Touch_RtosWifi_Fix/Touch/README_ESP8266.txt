STM32F407 + ESP8266（AT固件）集成说明
================================================

1) 接线（以常见 ESP8266-12E/12F “16Pin小板”命名为例）
------------------------------------------------
注意：ESP8266 只能用 3.3V 供电与IO，严禁直接接 5V。

必接：
- ESP8266 VCC      -> 3.3V（建议独立稳压，峰值电流>300mA）
- ESP8266 GND      -> GND（与STM32共地）
- ESP8266 TXD      -> STM32 PB11 (USART3_RX)
- ESP8266 RXD      -> STM32 PB10 (USART3_TX)
- ESP8266 EN/CH_PD -> 3.3V 上拉（10k）
- ESP8266 GPIO0    -> 3.3V 上拉（10k，正常启动必须为1）
- ESP8266 GPIO2    -> 3.3V 上拉（10k，正常启动必须为1）
- ESP8266 GPIO15   -> GND 下拉（10k，正常启动必须为0）
- ESP8266 RST      -> （二选一）
    A. 3.3V 上拉（10k）+ 按键复位；
    B. STM32 PB1（本工程默认启用硬件复位：PB1->RST，低有效），同时加10k上拉到3.3V

其余接口（若你模块正好有16个引脚，需要你“都接上”的话，建议按如下固定电平/预留）：
- GPIO12 / GPIO13 / GPIO14 / GPIO16：本工程未使用，可悬空或引出备用（建议不要悬空到外部噪声环境）
- ADC：本工程未使用，悬空
- 其他GND/VCC脚：按板子实际引脚接法分别接地/3.3V

2) WiFi参数
--------------------------------
打开文件：
  Touch/MDK/User/esp8266.h
修改：
  ESP8266_WIFI_SSID
  ESP8266_WIFI_PASSWORD

3) 使用方式
--------------------------------
- ESP8266 作为 STA 连接路由器后，会获取一个IP（由路由器分配）
- 手机上连接同一个路由器，在浏览器输入该IP即可访问主页
  主页会每5秒轮询一次 /state
  工作模式 = 1
  待机模式 = 0

4) 说明
--------------------------------
- 由于手机端使用浏览器访问，最可靠的方式是“浏览器轮询/自动刷新”来实现“每5秒更新”。
- 如果你希望“无请求也主动推送到手机”，需要手机端有可被连接的服务或使用WebSocket/UDP等方案，
  浏览器直连通常不具备被动接收的条件。
