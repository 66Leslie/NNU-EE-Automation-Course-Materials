# 水下大坝裂缝检测系统

基于深度学习的水下大坝裂缝图像检测网站，实现水下图像增强和裂缝检测功能。

## 功能特点

- **水下图像增强**：采用多尺度残差学习密集连接生成对抗网络(MLFcGAN)，解决水下环境低能见度、高浑浊度等问题
- **裂缝精准检测**：基于计算机视觉技术，实现对大坝裂缝的准确识别和定量分析
- **全面损伤评估**：提供裂缝数量、面积比例等定量指标，进行风险等级评估
- **友好用户界面**：直观的上传界面和结果展示，支持图像对比查看

## 系统架构

1. **前端界面**：基于Flask模板引擎构建，使用Bootstrap框架实现响应式设计
2. **后端处理**：Python实现的图像处理和深度学习模型
3. **核心算法**：
   - 水下图像增强：MLFcGAN (多尺度残差学习密集连接生成对抗网络)
   - 裂缝检测：基于边缘检测和轮廓分析的计算机视觉算法

## 安装使用

### 环境要求

- Python 3.8+
- CUDA 11.0+ (推荐，用于GPU加速)

### 安装步骤

1. 克隆仓库：
```
git clone https://github.com/yourusername/underwater-dam-crack-detection.git
cd underwater-dam-crack-detection
```

2. 创建虚拟环境：
```
python -m venv dam_env
source dam_env/bin/activate  # Linux/Mac
dam_env\Scripts\activate  # Windows
```

3. 安装依赖：
```
pip install -r requirements.txt
```

4. 运行应用：
```
python app.py
```

5. 访问网站：
在浏览器中打开 http://127.0.0.1:5000/

## 使用方法

1. 在首页点击"上传图像"或拖放图像到上传区域
2. 系统自动进行水下图像增强处理
3. 系统对增强后的图像进行裂缝检测分析
4. 查看检测结果，包括原始图像、增强图像和裂缝标记图像
5. 查看裂缝统计数据和风险评估建议

## 技术原理

### 深水环境水下图像增强算法

通过采用视觉传感器感知水下信息，考虑高坝深水环境弱视条件下低能见度、高浑浊度等特点，针对图像畸变和细节缺失等问题，构建深水环境图像增强方法，其中针对高浑浊度水域增强效果较好的深度学习方法。

#### 不基于衰减模型的学习方法

直接应用神经网络进行端到端的图像转换，学习低质量域到高质量域的映射函数。具体方法包括：

1. **卷积神经网络**：使用小型卷积神经网络实现水下图像的增强
2. **编码–解码网络**：在编码器中过滤噪声信号，在解码器中恢复细节信号
3. **生成对抗网络**：使用生成器和鉴别器进行图像增强，通过对抗训练提高图像质量
4. **多尺度残差学习密集连接生成对抗网络(MLFcGAN)**：
   - 网络结构：多尺度编码器–解码器结构
   - 损失函数：对抗损失、局部损失、域迁移损失、质量监督损失
   - 评估指标：PSNR、MSE、SSIM、FSIM
